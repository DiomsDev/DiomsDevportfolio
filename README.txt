PORTFOLIO DIOMSDEV — HTML / CSS / JAVASCRIPT

CONTENU
- index.html : structure des sections Accueil, À propos, Compétences, Formation et Contact
- style.css  : design responsive et animations CSS
- script.js  : menu mobile, Typed.js, ScrollReveal, navigation active et formulaire e-mail

OUVRIR LE PROJET
1. Décompresse le fichier ZIP.
2. Ouvre le dossier dans Visual Studio Code.
3. Ouvre index.html dans ton navigateur, ou utilise l'extension Live Server.

BIBLIOTHÈQUES INTÉGRÉES
- Boxicons : icônes
- Typed.js : texte animé
- ScrollReveal : animations au défilement
- Google Fonts : police Poppins

PERSONNALISATIONS À FAIRE AVANT PUBLICATION
1. Dans index.html, remplace ton.email@example.com par ton adresse e-mail réelle.
2. Dans script.js, remplace la valeur de destination par la même adresse.
3. Ajoute ton vrai profil LinkedIn et tes autres réseaux sociaux.
4. Vérifie les dates et les détails de formation/expérience.
5. Si tu veux un bouton pour télécharger ton CV, ajoute ton CV dans le dossier et un lien vers ce fichier.

NOTE
Le formulaire utilise mailto : il ouvre le logiciel de messagerie du visiteur et ne transmet pas les messages via un serveur. Pour un formulaire qui envoie directement les messages, il faudra connecter un service ou créer un back-end.
Les bibliothèques CDN nécessitent une connexion Internet.
